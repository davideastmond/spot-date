# SpotDate

## Live deploy

[SpotDate](https://spotdate.netlify.app/)

## About

A social media app that connects users via common musical tastes.

## Tech Stack

- Nuxt with VueJs and Typescript
- AuthJS
- Firebase Firestore

## External APIs

- Spotify Web API
- Algolia API for searching support
